# Changelog

## 5.0.0

PackApps returns with its university-era Swing interface, nine themes and fourteen astronomy backgrounds. Games, notes and the store now save locally in SQLite. Existing MySQL installations can reconnect with their own configuration. English and Spanish OCR and the Java 25 runtime travel with the application.

This release introduces Windows and Linux downloads and separate Intel and Apple Silicon Mac installers. The obsolete Bookverse browser automation menu has been retired. See the README for installation and SHA-256 verification.

## 4.0
