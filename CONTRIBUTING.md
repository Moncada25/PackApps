# Contributing

Use JDK 25 and the Gradle wrapper. Branch from trunk, keep changes focused and run `./gradlew clean build`. For UI changes include a screenshot and check an alternate theme. Test data changes on a fresh SQLite profile and a disposable MySQL instance. Credit new artwork and record its distribution license.

Open a pull request, resolve review conversations and keep the branch current. The required checks are validate and gitleaks. The maintainer can squash or rebase a green PR with zero outside approvals. [Community expectations](CODE_OF_CONDUCT.md)
